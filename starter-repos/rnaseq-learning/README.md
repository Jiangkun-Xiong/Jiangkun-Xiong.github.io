# A first bulk RNA-seq exercise

A planned public-data learning exercise in reproducible bulk RNA-seq analysis.

**Status:** Planned exercise; no completed analysis or results are included yet.

[Personal website](https://jiangkun-xiong.github.io/) · [Project background](https://jiangkun-xiong.github.io/learning/)

## Objective

Learn a bulk RNA-seq differential-expression workflow using a public teaching dataset and the original DESeq2 documentation.

## Planned outputs

- A README with dataset provenance and the biological comparison.
- An annotated R script or notebook.
- Dependency and session information.
- Regenerable figures with explanations of analytical choices and limitations.

## Status

This is a project scaffold and a learning plan. No analysis has been completed in this starter. Add the actual dataset source, commands, scripts and results as the work progresses.

## Original learning resource

[DESeq2 on Bioconductor](https://bioconductor.org/packages/release/bioc/html/DESeq2.html)

## Completion criterion

Another learner can reproduce the analysis from the instructions, regenerate its figures, and understand the main decisions and their limits.
