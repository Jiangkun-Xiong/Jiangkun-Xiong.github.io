Planning a first RNA-seq exercise

A scoped plan for a public-data learning exercise, with a clear definition of completion.

02

Project brief · Planned · 2026-10

A small, concrete objective

Use a public teaching dataset to learn the structure of a bulk RNA-seq differential-expression workflow. The goal is to understand and explain each step, then produce a compact analysis that another learner can follow.

Record the inputs

Keep the source link, dataset description, sample metadata and the biological comparison together. Explain which files are downloaded and which are generated by the analysis.

Keep a reviewable workflow

The planned repository will contain an annotated R script or notebook, dependency information, figures with captions and a README explaining how to run the analysis. Decisions and limitations should sit alongside the results.

Define completion honestly

This exercise is complete when the analysis can be rerun, its figures can be regenerated, and I can explain the comparison and the main analytical choices. Until then, it remains a learning plan.
