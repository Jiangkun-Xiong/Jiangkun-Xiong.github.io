STAGE 01 / SCORING

How is the FIS calculated?

An inspectable synthetic example of one step in the public implementation.

N

The inputs are entirely synthetic. The initial calculation and checks were prepared with AI assistance; my independent rerun and personal explanation remain to be recorded.

Read the input correctly

The three columns count miRNA, TF and protein-coding-gene neighbours. They are not RNA-seq read counts or TPM. Each column in this toy set ranges from zero to four.

Scale, then weight

Min-max scaling maps A to (0.25, 1, 0.75). The inspected upstream defaults are 0.22, 0.57 and 0.21.

0.25 × 0.22 + 1 × 0.57 + 0.75 × 0.21 = 0.7825

Explain A versus B

B has more total neighbours, but fewer TF neighbours. The larger default TF weight makes A score higher. Alternative weights can change the ranking. The inspected score is a weighted sum; a range from zero to one does not make it a calibrated probability.

Name the boundary and next question

The initial arithmetic and reference checks passed. This does not reproduce experimental-data processing, network construction, thresholds, GO or biological validation. Next ask where the neighbour counts come from.
