From a clinical question to a model

A short guide to connecting a question, physiological signals and a defensible interpretation.

01

Research reflection · 2026-10

Start with the comparison

Before choosing a model, write down the comparison. In my stroke project, the key distinction was the response to rising versus falling arterial pressure, considered in acute and subacute stroke. The clinical framing determines what should be compared.

Know what the signals represent

Mean arterial pressure and cerebral blood-flow velocity are measured quantities, with different physiological meanings. A useful analysis records how the signals were acquired and processed before interpreting a model output.

Connect the model to the question

The project used a direction-specific autoregressive moving average (ARMA) approach to examine step responses. For me, the useful learning task was to connect each analytical output with the question it could answer, while examining model assumptions.

Make the reasoning inspectable

A clear report should explain the question, data processing, analysis choices and interpretation. A future public repository can document the workflow using materials that are appropriate to share, and distinguish teaching examples from actual study results.
